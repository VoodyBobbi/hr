# HR-бот ПОЛАТИ

Чат-бот для найма рабочих на вахту. Отвечает кандидатам на вопросы о работе
и собирает с них анкету. Работает на сайте и в Telegram одновременно.

---

## Запуск за 4 шага

Нужен Python 3.11 или новее.

**1. Открыть папку проекта в терминале**

```powershell
cd "путь\к\папке\HR"
```

**2. Создать виртуальное окружение**

```powershell
python -m venv venv
```

**3. Включить его**

```powershell
.\venv\Scripts\activate
```

Слева в строке появится `(venv)`. На Linux и macOS команда другая:
`source venv/bin/activate`.

**4. Запустить**

```powershell
python start.py
```

Всё. Одна команда ставит зависимости, настраивает сертификаты, собирает
поисковый индекс и поднимает сайт с ботом.

Открывайте **http://localhost:8000**

Остановить — `Ctrl+C` в терминале.

> В PowerShell слово `start` само по себе занято системой, поэтому пишем
> полностью: `python start.py`.

### Что нужно вписать самому

Один раз, перед первым запуском. Откройте файл `.env` в корне проекта
(если его нет — он создастся при первом `python start.py`) и впишите ключ
GigaChat:

```
GIGACHAT_CREDENTIALS=ваш_ключ_из_личного_кабинета_Сбера
```

Остальное уже заполнено. Ключ шифрования программа создаст сама.

## Что происходит при запуске

Первый запуск занимает несколько минут: скачиваются библиотеки и модель
для поиска (около 470 МБ). Дальше запуск — секунд 20.

В конце вывода появится ваш ключ шифрования:

```
СОХРАНИТЕ Ключ шифрования анкет кандидатов.
ВНИМАНИЕ: потеряете ключ — не прочитаете уже собранные анкеты.

ENCRYPTION_KEY=N-OwSqWBRNsyloq5LI6...
```

**Скопируйте его в надёжное место** — менеджер паролей, заметку, что угодно.
Этим ключом зашифрованы все анкеты. Пропадёт файл `.env`, а копии ключа не
будет — прочитать анкеты не сможет никто, включая вас.

## Как это работает

Кандидат пишет вопрос. Бот отвечает одним из трёх способов, от самого
дешёвого к самому дорогому:

**1. Готовый ответ.** Если вопрос похож на один из записанных в
`data/faqs.json` — оттуда и берётся ответ. Нейросеть не задействована
вообще, ответ мгновенный и бесплатный.

**2. Через GigaChat.** Готового ответа нет — программа находит в базе знаний
несколько подходящих фактов и отдаёт их нейросети. Та формулирует ответ
своими словами, опираясь только на эти факты.

**3. Анкета.** Когда кандидат согласился оставить заявку, включается
пошаговый опрос из 29 вопросов. Здесь нейросети нет совсем: вопросы
заранее написаны, ответы проверяются на формат.

Такое разделение экономит деньги. Нейросети платят за объём текста, а
большинство вопросов кандидатов повторяются и до неё просто не доходят.

## Где что лежит

```
data/                   ← то, что бот знает
  faqs.json               готовые ответы на частые вопросы
  kb/                     база знаний по темам (11 файлов)
  system_prompt.md        правила поведения бота

frontend/index.html     ← страница сайта с чатом
backend/                ← код
candidates/             ← анкеты кандидатов (зашифрованы)
logs/                   ← кто что спрашивал
history/                ← переписка с каждым кандидатом
.env                    ← ключи и настройки
```

Папки `candidates`, `logs`, `history` и файл `.env` **никогда не попадают в
git** — там персональные данные. Программа создаёт их сама.

## Как поменять то, что говорит бот

### Добавить готовый ответ

Откройте `data/faqs.json` и допишите блок:

```json
{
  "question": "Есть ли на объекте интернет?",
  "keywords": "интернет вайфай связь мобильный",
  "answer": "На большинстве объектов есть мобильная связь и интернет. Качество зависит от удалённости — уточните у менеджера по конкретному объекту."
}
```

`keywords` — слова, которыми кандидат может спросить то же самое.
Чем их больше, тем лучше бот узнаёт вопрос.

Этот ответ уйдёт кандидату **дословно**, без участия нейросети. Пишите так,
как хотите, чтобы прочитал человек.

### Добавить факт для нейросети

Откройте подходящий файл в `data/kb/` и допишите:

```json
{
  "id": "cond.internet",
  "title": "Интернет и связь на объекте",
  "keywords": ["интернет", "вайфай", "связь", "позвонить домой"],
  "text": "На большинстве объектов есть мобильная связь..."
}
```

Такой факт нейросеть использует как справку и перескажет своими словами.

### Поменять характер бота

`data/system_prompt.md` — там правила: как разговаривать, что запрещено, как
длинно отвечать. Фактов о компании там нет и быть не должно, они в `data/kb/`.

### После правок

Просто перезапустите: `Ctrl+C`, потом `python start.py`. Программа сама
заметит изменения и пересоберёт поиск. Если ничего не меняли — пересборки
не будет, запуск пройдёт быстро.

## Telegram

### Бот для кандидатов

1. Напишите [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Полученный токен впишите в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=1234567890:AAA...
   ```
3. Перезапустите проект.

Бот отвечает только в личных сообщениях. В группах он молчит — это
специально, чтобы он не влезал в разговоры HR.

### Уведомления в HR-группу

Когда кандидат заполняет анкету до конца, в рабочую группу приходит
сообщение:

```
Новая заявка от кандидата
ФИО: Иванов Иван Иванович
Вакансия: Монтажник
Канал обращения: сайт

[ Показать все данные кандидата ]
```

Паспорт, СНИЛС и ИНН в самом сообщении **не показываются** — оно висит в
ленте и видно всем при пролистывании. Нажмите кнопку, и бот пришлёт полную
анкету отдельным сообщением.

Группа задаётся в `.env`:

```
TELEGRAM_HR_GROUP_CHAT_ID=-3869481165
```

Бота нужно добавить в группу участником, иначе он не сможет туда писать.

Если уведомления не приходят, попробуйте вариант с `-100` в начале:
`-1003869481165`. У обычных групп id без этого префикса, у супергрупп — с
ним, а группа становится супергруппой автоматически.

## Данные кандидатов

Анкеты лежат в `candidates/candidates.csv`, зашифрованные. Открыть их
Excel'ем не получится — это защита на случай, если файл куда-то утечёт.

Расшифровать и посмотреть:

```powershell
python -m scripts.export_candidates
```

Удалить данные кандидата по его требованию (152-ФЗ):

```powershell
python -m scripts.delete_candidate 7
```

где `7` — номер кандидата. Удалится всё: анкета, переписка, строки в логах.

Кандидат может удалить свои данные и сам — достаточно написать боту «удали
мои данные», он переспросит и удалит.

## Журнал

Всё пишется в **один файл** — `logs/logs.csv`. И разговоры с кандидатами, и
системные события. Колонка «Событие» говорит, что это за строка:

| Событие | Что значит |
|---|---|
| `dialog` | сообщение кандидата и ответ бота |
| `start` | проект запущен |
| `model` | загрузилась модель поиска (в «Время ответа» — сколько заняло) |
| `index` | пересобран поисковый индекс |
| `gigachat` | сбой обращения к нейросети |
| `notify` | уведомление HR-группе: ушло или нет |
| `delete` | удалены данные кандидата (след для 152-ФЗ) |
| `block` | кто-то заблокирован за спам |
| `marker` | отклонена попытка навязать анкету |

Колонка «Статус»: `ok`, `внимание`, `ошибка` — по ней удобно красить строки
в панели мониторинга.

**Что зашифровано, а что нет.** Вопросы и ответы кандидатов зашифрованы.
Комментарии к событиям, время, статусы и токены лежат открытым текстом.
Это сделано намеренно: панель мониторинга читает состояние системы
без ключа шифрования, а переписка для неё закрыта.

Из того же правила следует: если событие связано с текстом, который написал
человек, этот текст уходит в зашифрованную колонку «Вопрос», а в открытом
комментарии остаётся только факт.

## Расход на нейросеть

Пишется в `logs/logs.csv`, колонки «Токены на вход», «Токены на выход»,
«Всего токенов». Файл открывается Excel'ем, вопросы и ответы в нём
зашифрованы, а цифры — нет.

Пустые ячейки в этих колонках означают, что нейросеть не вызывалась: сработал
готовый ответ или шёл шаг анкеты. Чем больше таких строк, тем дешевле.

Посчитать итог:

```powershell
python -m scripts.token_report
```

## Если что-то не работает

**Бот отвечает только на часть вопросов, в терминале `CERTIFICATE_VERIFY_FAILED`**

Не установлен сертификат для GigaChat. Запустите `python start.py` — он
ставит его автоматически. Если не помогло, проверьте, что интернет доступен
и `gu-st.ru` не заблокирован.

**«Пока не могу сформулировать точный ответ»**

Либо нет связи с GigaChat (смотрите терминал), либо в `.env` не вписан
`GIGACHAT_CREDENTIALS`.

**Бот забывает разговор после каждого сообщения**

Проверьте `ALLOWED_ORIGINS` в `.env` — по нему программа определяет, локальный это
запуск или сетевой, и настраивает cookie. Для проверки на своём компьютере там должно
быть `http://localhost:8000`. При старте в консоли печатается строка `[app] Cookie
сессии: ...` — по ней видно, что именно определилось.

**«Вы отправляете сообщения слишком часто», хотя вы пишете медленно**

Защита от спама. Срабатывает на одинаковых сообщениях подряд быстрее чем раз
в полторы секунды. Блокировка снимается через 2 минуты сама. Настройки —
вверху `backend/rate_limiting.py`.

**Поиск находит не то**

Крутите пороги в `.env`:

- `FAQ_MIN_SIMILARITY` (сейчас 0.62) — насколько точно вопрос должен совпасть,
  чтобы отдать готовый ответ. Бот отвечает не по делу — поднимите до 0.70.
  Часто «не знает» того, что есть в базе — опустите до 0.55.
- `KB_MIN_SIMILARITY` (сейчас 0.35) — то же для фактов, которые уходят
  нейросети.

## Технические подробности

Если нужно копнуть глубже — подробные объяснения лежат в комментариях внутри
файлов. Коротко:

- **Поиск** — FAISS, индекс `IndexFlatIP` на нормализованных векторах, то
  есть косинусная близость от 0 до 1. Модель эмбеддингов
  `paraphrase-multilingual-MiniLM-L12-v2`, 384 измерения, работает локально.
- **Шифрование** — Fernet (AES-128-CBC + HMAC) из библиотеки `cryptography`.
  Шифруются анкеты целиком, а в логах и переписке — только тексты сообщений.
- **Защита от спама** — два уровня: лимит запросов с одного адреса (slowapi)
  и балльная система по поведению с затуханием баллов во времени.
- **Анкета** — детерминированная машина состояний, нейросеть в ней не
  участвует вообще.

Меняли модель или способ векторизации — поднимите `EMBEDDING_VERSION` в
`backend/build_index.py`, иначе индекс не пересоберётся и поиск сломается
молча.

```bash
docker compose up --build
```

Для сервера укажите в `.env` свой домен в `ALLOWED_ORIGINS` и поставьте перед
контейнером обратный прокси с HTTPS — остальное настроится само.

## Тесты

```powershell
python -m pytest
```

Ставить ничего не нужно — всё необходимое уже установилось при
`python start.py`.

89 проверок в 55 функциях, около секунды. Одна функция может проверять
несколько случаев — например, десяток разных формулировок согласия. Покрыта самая хрупкая часть — машина состояний
анкеты: согласие по 152-ФЗ, сбор полей, исправление, подтверждение,
удаление данных, защита от спама, проверка форматов.

Запускайте после любой правки в `backend/anketa.py`, `backend/assistant.py`
или `backend/validators.py`. Тесты работают на подставных данных во
временной папке — ваши анкеты они не трогают.
